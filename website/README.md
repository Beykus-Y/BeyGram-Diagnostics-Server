# BeyGram Website

Официальный сайт BeyGram на React + TypeScript + Vite. Основан на редакционной визуальной концепции из предоставленного Claude Designer standalone-экспорта: контрастная типографика, настраиваемые акценты, смартфон и интерактивные демо. Демо не использует реальные Telegram-данные.

## Локальная разработка

1. Перейти в `website/`.
2. Выполнить `npm install` и `npm run dev`.
3. Проверить сборку командой `npm run build`.

## Docker

Сайт — отдельный контейнер. Запуск: `docker compose --profile website up -d --build website`. Проверка: `curl -I http://127.0.0.1:8082/`.

Внешний nginx, уже обслуживающий `beygram.beykus.fun`, должен проксировать **только** публичный `location /` на `http://127.0.0.1:8082`. При этом более специфичные существующие location для `/api/v1/`, `/admin/`, `/healthz`, `/readyz` продолжают направляться на FastAPI 8080.

**Не заменять целиком текущий nginx-конфиг.** Сохранить действующую nginx-аутентификацию `/admin`, токен FastAPI, TLS и прокси-заголовки API без изменений. Ограничение по IP не добавляется. Репозиторий не содержит фактической конфигурации внешнего nginx.

Пример публичного маршрута внутри существующего HTTPS server:

    location / {
        proxy_pass http://127.0.0.1:8082;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

Сначала убедиться, что `/api/v1/*`, `/admin/*`, `/healthz` и `/readyz` уже выделены в более специфичные правила; иначе обратный прокси может направить API в SPA.

## Функции и ограничения

- Светлая и тёмная темы, семь цветовых акцентов, мобильное меню.
- Интерактивный телефон (демонстрационные чаты, диалог, аккаунты, темы, прокси) и ползунки оформления.
- Отдельная симуляция проверки прокси и демонстрация записи/воспроизведения медиа. Камера, микрофон, TDLib и API при этом не используются.
- Ссылки на GitHub Releases и Telegram-канал. Бета-тестирование — отдельная программа, доступ к исходникам и публичным сборкам не ограничен.
- Логотип временно берётся по raw URL из DEV ветки Android-клиента. Перед публикацией желательно закрепить ассет в папке `public/`.
- Шрифты берутся из Google Fonts с системными fallback (файлы шрифтов в репозиторий не добавлены).

## Тестирование

GitHub Actions проверяет сборку TypeScript и Vite. Интеграция в production-nginx намеренно не автоматизирована: нужен просмотр реальной конфигурации сервера перед включением.
